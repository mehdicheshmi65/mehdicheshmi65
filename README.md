## How I work

1. **Document first** — an automated system built on a wrong inventory just breaks things faster.
2. **Automate the repetition** — scripts handle the bulk; attention goes to the exceptions.
3. **Dry run before commit** — if a change cannot be reviewed or rolled back, it is not ready.
